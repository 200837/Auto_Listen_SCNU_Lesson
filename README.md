# Auto_Listen_SCNU_Lesson
这是一个基于python自动刷视频（只适用于华南师范大学砺儒云课堂）的项目
# 砺儒云课堂自动刷网课程序 · 使用文档

> 适用站点：华南师范大学砺儒云课堂 `https://moodle.scnu.edu.cn`
> 程序文件：`auto_play.py`
> 模式：**真实播放**（不伪造进度、不加速、不倍速、不跳转）

---

## 一、这是什么

一个用 Python + Playwright 写的自动刷网课程序。它模拟真人操作：

1. 登录统一身份认证（SSO）
2. 自动抓取你所有课程，让你选择要刷哪门
3. 统计该课程的视频数量（已看完 / 没看完）
4. 逐个打开未看完的视频，**从头真实播放到结束**
5. 播放器自己每 15 秒上报一次观看进度，播完自动标记"已完成"

程序**不会**帮你造假：不直接伪造上报请求、不 seek 跳进度、不加速、不倍速。视频有多长，它就会真实播放多久。

---

## 二、运行环境准备

### 1. 需要的东西

- Windows 电脑
- 系统自带的 Microsoft Edge 浏览器（程序直接用 Edge 内核，不用另外下浏览器）
- Python 解释器（程序依赖 Playwright）

### 2. 安装依赖（只需做一次）

打开 PowerShell，运行：

```powershell
python -m pip install playwright
```

> 程序用的是 `channel="msedge"`（调用系统 Edge），**不需要**再执行 `playwright install` 下载浏览器。

## 三、怎么启动

### 第一步：进入程序目录

打开 PowerShell，执行：

```powershell
cd "程序所在目录"
```

（把 `程序所在目录` 换成 `auto_play.py` 实际存放的文件夹路径）

### 第二步：启动程序

#### 方式 A：交互式启动（推荐新手）

```powershell
python auto_play.py
```

然后按提示操作：

```
请输入学号/账号: （输入你的学号）
请输入密码: （输入时不显示，输完回车）
```

接着程序会列出你的所有课程，例如：

```
可选课程:
  1. [5] 操作指南
  2. [20173] 大学生心理健康教育(南海2026)
  3. [19975] 程序设计基础C语言
  4. [19922] 军事理论与国家安全教育(26-27上学期)
  5. [19887] 大学生劳动教育理论和实践
请输入要刷的课程序号: 4
```

输入序号后，程序会显示该课程的视频统计并开始刷：

```
课程[19922] 视频统计: 总数 105，已完成 24，未完成 81
本次待刷: 81 个视频
```

#### 方式 B：一条命令直接指定课程

跳过选课环节，直接刷指定课程：

```powershell
python auto_play.py --user 你的学号 --pwd "你的密码" --course 19922
```

> 把 `你的学号` 换成实际学号，`你的密码` 换成实际密码。

---

## 四、命令行参数说明

| 参数 | 作用 | 是否必填 |
|------|------|----------|
| `--user` | 学号 / 账号 | 否（不传则交互输入） |
| `--pwd` | 密码 | 否（不传则交互输入） |
| `--course` | 课程 id | 否（不传则交互选课） |

示例：

```powershell
# 只传账号密码，交互选课
python auto_play.py --user 你的学号 --pwd "你的密码"

# 全参数，直接刷课程 19922
python auto_play.py --user 你的学号 --pwd "你的密码" --course 19922
```

> 课程 id 怎么找？课程页网址里的 `id=` 后面那串数字就是，例如
> `https://moodle.scnu.edu.cn/course/view.php?id=19922` → 课程 id 是 `19922`。

程序会实时打印带时间戳的日志：

```

...
[11:39:xx]  已通过「学习确认」弹窗
...
[12:08:xx]  ✔ 收到播放器 finish=1 上报，视频已完成
```

- `已通过「学习确认」弹窗`：遇到超过 10 分钟视频的人机验证弹窗，程序已自动按住按钮通过。
- `✔ 完成`：该视频已播完并标记完成。

## 六、断点续传

程序把已经完成的视频 id 存到同目录的 `completed.json` 里。

- 中途关掉程序、电脑重启、断网，都没关系。
- 下次重新启动，程序会自动跳过 `completed.json` 里已完成的视频，接着刷剩下的。

`completed.json` 内容大概长这样：

```json
["876917", "876919", "876922"]
```

> 想从头重刷，删掉 `completed.json` 即可。

## 七、常见问题

### 1. 报错 `ModuleNotFoundError: No module named 'playwright'`

没装依赖，执行：

```powershell
python -m pip install playwright
```

### 2. 提示浏览器相关错误

程序用的是系统 Edge。请确认电脑装了 Microsoft Edge（Win10/Win11 一般自带）。

### 3. 视频播放卡住不动

程序会自动检测：如果连续约 2 分钟播放时间没前进，会刷新页面重试。

### 4. 密码里有特殊符号（如 `!`）

用方式 B 传参时，密码要用双引号包起来：

```powershell
--pwd "你的密码"
```

### 5. 想看实时画面，不想用无头模式

程序默认 `headless=True`（后台无窗口运行，更省资源）。如果想看浏览器窗口，把 `auto_play.py` 里：

```python
browser = p.chromium.launch(channel="msedge", headless=True)
```

改成：

```python
browser = p.chromium.launch(channel="msedge", headless=False)
```

### 6. 想刷多门课

跑多次程序，每次用 `--course` 指定不同课程 id 即可。或者不带 `--course`，每次交互选不同的课。
